## Du conseil aux outils du quotidien

**Actigence accompagne la transformation, de la stratégie aux opérations. Actigence Code développe les logiciels qui soutiennent ce travail.** La constellation réunit des outils pour recueillir l’information, partager des ressources, animer les échanges et éclairer les décisions. Chaque service a une fonction précise ; les liens entre eux rendent l’ensemble utile.

Les espaces de travail et certaines applications nécessitent un compte autorisé. Le Hub présente ses propres modules ; les autres services restent accessibles par leurs liens directs.

## Les liens qui donnent du sens à l’ensemble

- **Un lien court pour chaque échange.** Forms diffuse un formulaire, Share un téléchargement, Interact une session de participation. Links fournit les URL **amc.tf** qui les rendent faciles à partager, y compris par QR code.
- **Une expérience visuelle commune.** Theme apporte les couleurs, fontes, icônes et réglages d’apparence ; UI apporte les composants React. Forms, Stock et Movies réutilisent ces fondations en conservant leurs fonctions propres.
- **Un accès et un support cohérents.** [Actigence SSO](https://auth.actigence.eu) assure la connexion des services intégrés à Authentik ; Helpdesk accompagne leurs utilisateurs. Les droits restent définis par chaque application.
- **Des décisions appuyées sur des faits.** Le Hub rassemble les modules métiers. Capacity simule la charge des équipes qualité. Logger et sa [console Audit](https://log.actigence.eu) rendent les événements des applications instrumentées consultables par les administrateurs.

## Le code derrière les services

Nous développons des applications, des bibliothèques partagées et des intégrations avec des projets comme **Claper, Plik, Shlink, Authentik et Plausible**. Les descriptions des dépôts précisent leur rôle, leurs liens avec la constellation et leur portée actuelle. Les prototypes sont présentés comme tels.

Le [fork public de Plausible Analytics](https://github.com/Actigence-Code/actigence-analytics) conserve son origine et sa licence. Ce [dépôt communautaire](https://github.com/Actigence-Code/.github) porte la présentation et les règles communes. Les autres dépôts sont accessibles selon les autorisations accordées.

**Actigence supports transformation from strategy to operations. Actigence Code builds the software behind that work.** Its constellation connects focused applications for collecting information, sharing resources, involving people and informing decisions.

| Service | Purpose |
| :--- | :--- |
| [Actigence](https://actigence.eu) · [Hub](https://hub.actigence.eu) | Consulting and transformation; entry point for business modules. |
| [Forms](https://forms.actigence.eu) · [Share](https://share.actigence.eu) · [Interact](https://interact.actigence.eu) | Collect responses, transfer files and engage a live audience. |
| [Links](https://links.actigence.eu) | Shared **amc.tf** short URLs for forms, downloads and participation sessions. |
| [Stock](https://stock.actigence.eu) | Reviewed illustrations, variants and original downloads. |
| [Capacity](https://capacity.actigence.eu) | Quality-team workload and capacity scenarios. |
| [Academy](https://lms.actigence.eu) · [Movies](https://movies.actigence.eu) | Quiz-based learning; movie library management. |
| [SSO](https://auth.actigence.eu) · [Helpdesk](https://help.actigence.eu/helpdesk) · [Audit](https://log.actigence.eu) | Sign-in for integrated services, application support and administrator event review. |

**Shared foundations:** Theme provides visual tokens and appearance settings; UI provides React components; Core provides platform contracts; Logger provides structured events and audit tooling. Each application owns its data, permissions and business rules. A shared appearance does not imply shared data or synchronized preferences.

Some services require an authorized account. Hub lists its own business modules; other services have direct entry points. Public repositories retain their individual upstream attribution and licences. Prototype and integration scope is described in each repository.
