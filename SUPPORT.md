# Support

Use the [README](README.md) for setup and the [documentation index](docs/README.md) for detailed guides. Check existing issues before opening another report.

## Bugs and questions

When repository issues are available, include the release or commit, relevant runtime versions, the smallest reproducible example, expected behavior and actual behavior. State which checks you ran. Use the documentation issue template for unclear or outdated instructions.

Use synthetic examples. Remove credentials, personal information, client content, private hostnames and machine-specific paths from every report, log and screenshot.

If you cannot access the issue tracker, use your established maintainer contact or the [Actigence website](https://actigence.eu). Repository access and issue availability depend on the project; this document does not promise a service level or support entitlement.

For a suspected vulnerability, follow the private process in [SECURITY.md](SECURITY.md).
