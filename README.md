## Maintaining the profile

Keep the organization page concise, accurate, and safe for a public audience. The profile uses French with an English section; the service map and repository descriptions cover both languages. Use examples that contain no private infrastructure, customer information, personal details, credentials, or internal evidence.

The banner is a local SVG with no external assets, scripts, or tracking. Its official Actigence symbol is reused as vector artwork; service nodes illustrate relationships rather than automatic data transfers. Preserve its accessible title and description when changing the artwork. Verify relative links from this file and the service map, and absolute links used on the organization profile, before publishing.

Repository visibility and licensing are defined by each repository. An organization profile does not grant access to other projects or change their terms.
