## Maintaining the profile

Keep the organization page concise, accurate, and safe for a public audience. Use English and examples that contain no private infrastructure, customer information, personal details, credentials, or internal evidence.

The banner is a local SVG with no external assets, scripts, or tracking. Preserve its accessible title and description when changing the artwork. Verify relative links from both this file and `profile/README.md` before publishing.

Repository visibility and licensing are defined by each repository. An organization profile does not grant access to other projects or change their terms.
